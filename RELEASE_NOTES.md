# RoomCraft Studio 1.1.0-rc3

The calibrated V0.9 RoomCraft Geometry Adapter is now the default geometry option with RoomCraft LoRA, labeled **Preserve Room Geometry — RoomCraft RGA**, with a visible OFF switch. Initial/reset unchanged-Qwen behavior and the pinned inference/training stacks are preserved. No trained tensors changed.

The genuine matched Underwater demonstration shows improved wallpaper and room framing without the invented ceiling. This is one positive real-photo example; consistent benefit, monitor-count accuracy and exact geometric preservation remain unproven. [Evidence](docs/RGA_VALIDATION.md).

Four room purposes, six themes, comparison/download/history controls, and optional local mask compositing remain. The final audit uses CPU and browser checks only. RC1/RC2 archives, checkpoints and private raw comparison records remain intact. No paid compute, retraining, publication or unrelated-resource changes are part of this audit.

The source ZIP includes rights-attributed demonstrations, sanitized evidence and a per-file SHA256 manifest. It excludes weights, full datasets, caches, private account records and external asset binaries. Private adapter availability, pinned worker vulnerabilities and the UI Pillow bounds exception remain disclosed limitations.
